# eBlocksApi

Generated by the `eblocks-api` template from [eBuildingBlocks](https://github.com/ghazi1567/eBuildingBlocks).

## Run it

```bash
dotnet run --project eBlocksApi.API
```

This opens the Scalar API docs at `/scalar` (via the `launchUrl` in `launchSettings.json`). Try `GET /api/products`, then `POST /api/products` with `{ "name": "Widget", "price": 9.99 }`.

No database or external services required — `Products` are stored in an EF Core in-memory database that resets on restart. Swap it out in `eBlocksApi.Infrastructure/DependencyInjection/InfrastructureExtensions.cs` (`options.UseInMemoryDatabase(...)` → `options.UseSqlServer(...)`) when you're ready for real persistence.

## What's wired up

- `eBlocksApi.Domain` — the `Product` entity, an `AuditableEntity<Guid>`, plus a `ProductCreatedEvent` domain event.
- `eBlocksApi.Application` — `ProductDto`.
- `eBlocksApi.Infrastructure` — `AppDbContext` (`TenantAwareDbContext`), audit interceptor, repository/unit-of-work registration.
- `eBlocksApi.API` — `ProductsController` (list/get/create) and `Program.cs` wiring `BaseRegister`/`BaseAppUse`.

## Next steps

- **Real database**: switch the EF Core provider (see above) and add a migration.
- **Multi-tenancy**: flip `Features:MultiTenancy:Enabled` to `true` in `appsettings.json` and make `Product` implement `ITenantEntity` (or inherit `TenantEntity<Guid>`) — see the [multi-tenant SaaS quickstart](https://github.com/ghazi1567/eBuildingBlocks/blob/latest-dotnet-10/docs/examples/multi-tenant-saas-quickstart.md).
- **Reliable event publishing**: `ProductCreatedEvent` is raised but not dispatched yet — wire up the transactional outbox or the in-process event bus, see the [outbox quickstart](https://github.com/ghazi1567/eBuildingBlocks/blob/latest-dotnet-10/docs/examples/reliable-events-with-outbox.md).
- **Everything else** (auth, Hangfire, Redis, OpenTelemetry, MassTransit): each is a feature flag under `Features` in `appsettings.json` — see the [main README](https://github.com/ghazi1567/eBuildingBlocks#-configuration-requirements) and [docs/examples](https://github.com/ghazi1567/eBuildingBlocks/blob/latest-dotnet-10/docs/examples/README.md).
